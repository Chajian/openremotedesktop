# PR 11 code quality and regression plan

> Execute the approved repair request continuously. Use focused regression tests and an independent final code review. This plan records scope; it does not authorize publication.

**Goal:** Repair executor resource ownership, preserve MCP tool contracts, and verify Desktop Commander 0.3.1 without regressing older Agents or Operation Recovery.

**Architecture:** Keep physical client ownership until shutdown is confirmed. Serialize lifecycle operations within ExecutorManager, retain the existing Relay protocol, and assemble executor identity and capability validation at runtime. Shared tool contracts remain independent of the upstream runtime.

**Tech stack:** TypeScript, Node.js 24, pnpm 10.12.3, Vitest, MCP stdio, WebSocket.

**Spec:** The approved PR 11 repair request; source baseline `9b2d65eedd0639805db7df99c4f6dba067133803` and [PR 11](https://github.com/Chajian/openremotedesktop/pull/11).

## Review focus

- A child returned after close/invalidation must remain owned and must not publish READY.
- Failed cleanup must retain a retryable handle and block a second live executor.
- A callback from a retired child must not invalidate its replacement.
- Socket loss and executor replacement must never cause replay of side effects.
- A static public catalog must not claim a platform-specific shell or an unsupported tool on an accepted Agent.
